# 💬 GrobGram

**Стильный мессенджер для общения через интернет**

![GrobGram](https://img.shields.io/badge/version-1.0-purple)
![License](https://img.shields.io/badge/license-MIT-blue)
![Firebase](https://img.shields.io/badge/Firebase-Realtime%20DB-orange)

## 🚀 Возможности

### 💬 Общение
- Личные чаты и групповые чаты
- Отправка текста, фото, голосовых сообщений
- Реакции на сообщения ❤️👍😂🔥
- Пересылка сообщений
- @Упоминания пользователей
- Ответ на сообщения (цитирование)

### 🎤 Звонки
- Аудио звонки (WebRTC)
- Видео звонки (WebRTC)

### 🎨 Оформление
- Тёмная/светлая тема
- 7 цветов акцента
- Обои для чата
- Настройка шрифта и стиля сообщений

### 👥 Группы
- Создание групп с описанием
- Права участников (владелец/админ)
- Пригласительные ссылки
- Закреплённые сообщения

### 🔒 Безопасность
- Скрытые чаты с паролем
- Блокировка пользователей
- Автоудаление сообщений
- Режим невидимки

### ⚙️ Профиль
- Аватарка, био, подпись
- Музыка профиля
- Кастомный звук уведомлений
- Автоответчик

### 👑 Админ-панель
- Статистика пользователей
- Список всех зарегистрированных

## 📦 Установка

### Быстрый старт
1. Скачай `grobgram.html`
2. Загрузи на [GitHub Pages](https://pages.github.com), [Netlify](https://netlify.com) или [Vercel](https://vercel.com)
3. Открой ссылку и начни общение!

### Локальный запуск
Просто открой `grobgram.html` в браузере!

## 🔧 Технологии

- **HTML5 + CSS3 + JavaScript**
- **Firebase Realtime Database** — хранение данных
- **WebRTC** — аудио/видео звонки
- **QRCode.js** — генерация QR-кодов

## 📱 Поддерживаемые платформы

- 💻 Десктоп (Chrome, Firefox, Edge)
- 📱 Мобильные (iOS Safari, Android Chrome)

## 🤝 Как использовать

1. Зарегистрируйся с ником и паролем
2. Скопируй свой ID
3. Отправь ID другу
4. Или найди друга по нику через поиск
5. Начните чат!
